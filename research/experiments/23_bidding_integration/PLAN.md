# Exp 23 — Bidding-loop integration (full ladder)

Goal: turn the exp-22 contract suite (oracle + configurable solver + the full
value-ordered ladder) into a real auction that bids the **entire ladder up to the
48-point game**, not the 4-contract toy from exp 17.

## Architecture decision (milan + Claude, 2026-06-17)

NOT a monolithic net over ~22 rungs. The ladder is generated by a tiny **combo
basis** crossed with deterministic multipliers, so we predict a handful of
**base events** and let the oracle + ladder arithmetic compose every rung.

- **Colored net** (trump present, 10-below-Ace rank): base events
  `P(parti)`, `P(ulti made)` + silent-7 outcome, `P(reach100|40)`,
  `P(reach100|20)`, `P(colored sweep)`. Also drives pickup discard.
- **Colorless net** (no trump, 10-low rank): `P(betli)`, `P(colorless duri)`.
  SEPARATE per the exp 18/19 result (structure/void-driven, rank regime flips).
- **Compose:** every rung's E[GP] = base-event probs × oracle GP rates ×
  piros/terített ×2. Decision = the Σsq-ordered ladder + overtake / equivalent-
  pair / rebetli-double-rung / pass-floor.

The split boundary = **trump vs no-trump = rank-regime boundary** (principled).

## Label source decision (revised after the latency review)

The ~700–800 ms solve tail is **exclusively** `multi[+silent_ulti]` (trump-7
cull-isolation). Everything else is ≤3.4 ms mean. So:
- **Train on GOD labels** (1 solve / contract / deal — no 32× PIMC blowup) +
  the existing debias/calibration (exp 16 isotonic, exp 20 DEBIAS_BID) for
  perfect-info overconfidence. NOT live-PIMC32 labels at scale.
- For the rung *decision* use the **dedicated** solvers (sub-2 ms), not the
  multi beast. Reserve live PIMC for small-N head-to-head strength reference.
- Fix the `silent_ulti` cull (the one bottleneck) so the multi co-solve is
  affordable when we want the silent-rider EV in one shot.

## Build order

1. **Ladder controller** (`ladder.py`) — pure logic, no ML. The 22-rung
   value-ordered ladder around `BidSet`, overtake / equivalent-pair / rebetli /
   pass-floor, adapters to the legacy `(contract, trump)` tuple. ✅ tested vs the
   milan-confirmed table (`test_ladder.py`).
2. **`silent_ulti` cull fix** — verify vs `21/test_cull_silent_ulti.py`
   (0 mismatches) + whole-game deterministic eval (byte-identical); re-benchmark.
3. **God-label generation** for the base events (extend `17/gen_alpha0.py`):
   add `reach100|40`, `reach100|20`, `colored sweep` heads to the colored set;
   keep betli + colorless duri on the colorless set. Background job, heartbeat logs.
4. **Train baseline** colored multi-head + colorless nets; small head-to-head.
   Marked as a baseline for review — net architecture is milan's call to confirm.
5. **Wire into the auction** — drop-in replace `auction_h2h.contract_rank` with
   the ladder (behind a flag, old one preserved), bid valuations from the nets.
